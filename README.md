# Knowlaborator plugins for Codex

Add this Git repository as a marketplace in Codex:

https://github.com/Highner/knowlaborator-plugins

Select your organization's plugin, choose Install, and sign in to Knowlaborator
when prompted. Start a new task to use its skills and tools.

Available organizations: Lausu.

If your Codex version only offers command-based marketplace setup, run:

```sh
codex plugin marketplace add https://github.com/Highner/knowlaborator-plugins
```

Then install the organization plugin from the plugin browser. If you previously
installed the same organization from a downloaded marketplace, uninstall that copy
in Codex before installing this one so its tools do not appear twice.

This repository contains generated skills, plugin manifests, and public MCP URLs.
Organization names and IDs are public. It contains no account credentials,
installation keys, documents, or organization data. Installing a plugin grants no
access: Knowlaborator checks your signed-in account, membership, and Workspace
permissions on every request. Manage plugin installation in Codex and service
access in Knowlaborator. Updating or uninstalling a plugin does not revoke OAuth access.

The marketplace is published from an explicitly maintained organization list.
New organizations are not automatically made public. To request an addition or
report an issue, contact info@appligator.de or visit https://orgapp-production-1b56.up.railway.app/plugin/support.

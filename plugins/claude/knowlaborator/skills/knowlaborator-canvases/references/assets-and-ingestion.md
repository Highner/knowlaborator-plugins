# Images on a board

Board images are files owned by one board. They are not Documents, global-search results, Knowledge sources or
Document processing inputs. A person can save one as a Document in the browser. You upload only images you generated
or downloaded: PNG, JPEG, GIF or WebP up to 104,857,600 bytes (100 MiB).

Show an image that is already a Document as a record suggestion of that Document (`suggest_record`, kind `document`).
Do not download and re-upload it, and do not search the web for a substitute.

Image bytes never pass through MCP arguments. Inspect the local file with your ordinary local-file tools. Never put
its path, bytes, upload URL, credentials or tokens in an MCP argument or summary.

## Upload

1. **Check the board.** Confirm it is active and that your person is a Contributor or Manager of its Workspace.
2. **Begin.** Determine the leaf file name, exact byte size and lowercase hex SHA-256 of the bytes. Call
   `begin_canvas_asset_upload` with the board id and:

   ```json
   {
     "fileName": "key-visual-idea.png",
     "mediaType": "image/png",
     "byteSize": 482113,
     "sha256": "3f1a…64 lowercase hex characters…",
     "idempotencyKey": "board-0193a9f1-asset-key-visual-01"
   }
   ```

   The response returns `uploadIntentId`, `url`, `method`, `headers`, `expiresAt` and `maximumByteSize`. The intent
   lives one hour.
3. **Send the bytes.** Send only the raw bytes to the returned URL, with its exact method and headers. Send no JSON,
   multipart form, MCP authorization or cookies, and do not repeat the URL afterwards.
4. **Complete.** Call `complete_canvas_asset_upload` with the board id and `uploadIntentId`. OrgApp verifies the size,
   SHA-256 and format and returns `assetRevisionId`.
5. **Place it** with `change_canvas`:

   ```json
   { "op": "add_image", "itemId": "…", "assetRevisionId": "…", "source": "generated",
     "title": "Key visual idea, northern lights over the harbor",
     "caption": "From the Nordlicht brief", "altText": "Northern lights over a harbor at night", "near": "…", "side": "right" }
   ```

   Use `"source": "downloaded"` with the image's `sourceUrl` (https) for a downloaded image. The board shows
   "Generated by Anna's agent" or the source address.

## Interruptions

- **Retry.** Retry `begin_canvas_asset_upload` with the same idempotency key and identical metadata while the intent
  is valid; it returns the same intent. Then send the bytes again if needed and retry `complete_canvas_asset_upload`.
- **Errors.**
  - `CANVAS_ASSET_UPLOAD_EXPIRED`: begin a new intent with a new key.
  - `CANVAS_ASSET_UPLOAD_MISMATCH`: the stored bytes differ from the declared size or digest.
  - `CANVAS_ASSET_UPLOAD_INCOMPLETE`: nothing arrived.
  - `CANVAS_ASSET_UNSUPPORTED`: the bytes are not a supported image.
- **Never upload twice** merely because the outcome is uncertain.

## Looking at images

`get_canvas_asset_file` returns a link to the exact original of any image on the board, with its SHA-256. Download it
and inspect the saved file. Saving an image as a Document is the person's browser action.

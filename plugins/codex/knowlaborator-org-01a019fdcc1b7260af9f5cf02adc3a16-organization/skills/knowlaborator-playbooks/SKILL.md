# Knowlaborator Playbooks

Choose the requested mode and load only its reference:

- [playbook-discovery.md](references/playbook-discovery.md) for process discovery,
  mail-context matching, advice or execution. Advice offers execution; it does
  not start it. Triage uses its own summary-and-proposal workflow.
- [playbook-authoring.md](references/playbook-authoring.md) for an explicit
  create or edit request when authoring tools are exposed.
- [playbook-lifecycle-and-removal.md](references/playbook-lifecycle-and-removal.md)
  for activation, retirement or browser-only deletion.

A Playbook has one current body, not revisions or Case snapshots. Active edits
apply immediately to existing and future Cases. Content and Template references
are advisory, never authority or confirmation. Cases owns tracked execution and
lifecycle; authoring a Playbook does not authorize Case work.
